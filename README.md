# TetrIrene
A Flutter-based *Tetris* clone.

## Getting Started

To run the Flutter Tetris app, follow these steps:

1. Ensure you have Flutter installed. If not, follow the instructions at [flutter.dev](https://flutter.dev/docs/get-started/install).

2. Clone the repository:
   ```
   git clone https://github.com/mcortecchia/tetrirene.git
   cd tetrirene
   ```

3. Get the Flutter packages:
   ```
   flutter pub get
   ```

4. Run the app:
   ```
   flutter run
   ```

The app should now be running on your connected device or emulator.
